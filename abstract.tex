Machine learning models deployed in production environments frequently experience distribution drift---changes in input feature distributions over time that can degrade model performance. While discriminative methods like D3 have proven that adversarial validation can accurately detect drift, they suffer from the ``black box'' problem---providing no insight into the source of the drift. In complex MLOps pipelines, knowing \textit{that} drift occurred is insufficient; engineers must understand \textit{what} drifted to take appropriate corrective action.

This thesis proposes \textbf{Explainable Adversarial Drift Detection (EADD)}, a novel framework that extends adversarial validation with SHAP-based root cause analysis. Unlike univariate methods (e.g., KSWIN) that flood users with alerts for every feature, EADD employs a multivariate permutation test to robustly flag significant shifts, followed by an automated diagnostic step that ranks features by their contribution to the drift. This transforms the drift detector from a simple alarm into an intelligent diagnostic tool.

The main contributions are: (1) a streaming adversarial validation framework with LightGBM and reservoir sampling for representative reference windows, validated through permutation testing ($B=50$, $\alpha=0.01$); (2) SHAP-based root cause analysis that identifies which specific features drive detected drift; (3) automated drift prescriptions providing actionable remediation recommendations based on drift patterns (univariate, multivariate, or feature-subset drift); (4) benchmarking against D3 and seven state-of-the-art unsupervised detectors on the Lukats et al. (2025) real-world data streams; and (5) practical implementation guidelines for MLOps deployment.

Experimental evaluation across four experiments demonstrated that EADD detects all four temporal drift types (abrupt, gradual, incremental, recurring) with 100\% success rate while D3 detects only 2/4; achieves 0\% missed detection rate across 13 real-world benchmark datasets with 3.7\% lower mean time to detection than D3; produces zero false alarms on stable data including challenging autocorrelated streams where D3 triggers up to 87.4 false alarms (Mann--Whitney $p = 0.0101$); and correctly identifies drifting features via SHAP in all controlled scenarios (AUC 0.767--0.801). EADD advances beyond detection accuracy to actionable diagnostics, addressing the critical explainability gap identified in recent benchmarks.
