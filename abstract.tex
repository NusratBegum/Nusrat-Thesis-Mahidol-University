Machine learning models deployed in production environments frequently experience distribution drift---changes in input feature distributions that degrade model performance. Existing unsupervised detectors signal \textit{that} drift occurred but provide no insight into \textit{which} features drifted or what corrective action is appropriate.

This thesis proposes Explainable Adversarial Drift Detection (EADD), a framework that integrates discriminative classification with permutation-based significance testing and SHAP-based feature attribution in a unified streaming pipeline. EADD trains a LightGBM classifier to distinguish reference from current data, confirms drift via a permutation test, and applies TreeSHAP to identify which features drive detected drift, classifying patterns into univariate, subset, or multivariate categories with corresponding remediation recommendations.

Experimental evaluation across four synthetic drift types and 11 benchmark datasets, comparing eight unsupervised detectors, demonstrated that EADD detected all four drift types with near-zero false alarms---a balance no other detector achieved. SHAP-based feature attribution correctly identified drifting features in all controlled scenarios (P@k = R@k = F1@k = 1.0) with 100\% prescription accuracy. The permutation test significantly reduced false alarms compared to threshold-based approaches (Mann--Whitney $p = 0.013$). EADD advances drift detection from a binary alarm to an actionable diagnostic tool.
}

EADD provides both broad drift type coverage and actionable root cause explanations, enabling MLOps teams to diagnose and respond to drift with targeted corrective actions---such as fixing a specific data pipeline for univariate drift or triggering full retraining for multivariate concept shift---rather than treating all drift signals as equivalent alarms requiring indiscriminate model retraining. This reduces unnecessary retraining costs, accelerates incident response, and supports regulatory transparency requirements in production machine learning systems.
