\abstract{%
\linespacing{1.2}
Machine learning models in production can lose accuracy when their input features drift. Classifier-based detectors such as D3 use a sliding reference that can miss slow drift and an uncalibrated threshold that raises false alarms on autocorrelated streams, and they do not report which features changed. This thesis studies adversarial validation, a classifier two-sample test (C2ST), for unsupervised feature drift detection and proposes the Explainable Adversarial Drift Detector (EADD). EADD compares the newest window with a reservoir sample of the data since the last alarm, confirms each alarm with an adaptive sequential permutation test (ASPT) whose null comes from earlier windows of the same stream, and ranks the drifting features with TreeSHAP. Four hypotheses, registered before the final runs, were tested on 34 streams against D3 and D3 with the same LightGBM classifier (D3-LightGBM); all four were supported. On slow (gradual or incremental) drift, EADD had a recall of 1.00 against 0.53 for D3-LightGBM and a mean time to detection of 443 against 879 samples, and on abrupt drift it stayed within the registered margin of 50 samples (115 against 122; Holm $p \le 0.023$ for all three tests). On autocorrelated streams without drift it raised 5.6 false alarms per 10{,}000 samples against 19.5 for D3-LightGBM (Holm $p = 0.023$). ASPT gave equivalent recall, delay and false alarms with 52 instead of 163 permutations per test. TreeSHAP attribution in a classifier-based detector, measured with EADD, ranked the truly drifting features above chance (precision@k 0.75 against 0.31, $p < 0.001$), although a per-feature Kolmogorov--Smirnov ranking was more accurate (0.97). The results support a reservoir reference with a history-based null for slow feature drift with few false alarms; on abrupt drift EADD is equivalent, not better.
}
