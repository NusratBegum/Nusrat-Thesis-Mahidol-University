\abstract{%
\linespacing{1.2}
Machine learning models in production can lose accuracy without warning when the distribution of their input data drifts. This thesis studies adversarial validation, in which a classifier is trained to tell reference data from recent data, as a technique for unsupervised feature drift detection. It proposes Enhanced Adversarial Drift Detection (EADD), which extends the discriminative detector D3 with a reservoir-sampled reference window, a permutation test that confirms each alarm, prediction entropy monitoring and a TreeSHAP feature ranking. Its adaptive sequential permutation test (ASPT) stops the permutation test early when the evidence is clear. EADD was compared with D3, using the same LightGBM classifier and window sizes, and with six other unsupervised detectors on thirteen real-world data streams, four of them with annotated drift points. On the annotated streams, EADD did not outperform D3: its mean recall was lower (0.50 vs.\ 0.65), its mean time to detection longer (302 vs.\ 279 samples) and its false alarms more frequent (8.9 vs.\ 5.6 per run), so the hypotheses that EADD detects more, sooner and with fewer false alarms were not supported. Most drifts that EADD missed had been signalled shortly before the annotated point. ASPT gave the same detections as a full permutation test in all runs with less runtime, and at low AUC thresholds it reduced false alarms by up to 81\%. On the streams without annotations, EADD and D3 gave almost the same classifier accuracy.
}
